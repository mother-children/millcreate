書き出し日：2026年9月9日（原稿v2.4準拠）

・index.html をブラウザで開くと、ナビやリンクから全ページを回遊できます。
・写真は photos/ に格納し、全ページから共有参照しています。
・support.js / image-slot.js はページ描画に必要です。同じ階層に置いたまま扱ってください。
・表示にはインターネット接続が必要です（Webフォントと描画ライブラリを外部から読み込みます）。
・グレー一色の画像は、素材未確定のプレースホルダーです。
